## Technical Highlights

### OAuth 2.0 Implementation
- PKCE flow for secure authorization
- State parameter for CSRF protection
- Automatic token refresh on expiration
- Token revocation support

### Data Mapping
- Xero Invoice → StandardTransaction (INVOICE or BILL type)
- Xero BankTransfer → StandardTransaction (BANK_TRANSFER type)
- Xero Contact → StandardContact (with type inference)
- Xero Account → StandardAccount (with type mapping)
- Handles missing fields gracefully
- ISO 8601 date parsing with timezone support
- Decimal arithmetic for monetary amounts

### Error Handling
- 401 Unauthorized → AuthenticationError
- 404 Not Found → NotFoundError
- 429 Rate Limited → RateLimitError
- 400+ → APIError with Xero-specific message extraction
- Timeout handling (30-second limit)
- Request exception handling

### Rate Limiting
- Tracks X-Rate-Limit-Remaining-Minute header
- Prevents exceeding 60 calls/minute limit per tenant

### Pagination
- While loops with page parameter
- Continues fetching until limit reached or no more pages
- Supports filtering by date range (invoices only)

## Challenges & Solutions

### Challenge 1: Token Expiration in Tests
**Problem**: Tests setting `expires_at: datetime.now()` caused token to appear expired
**Solution**: Changed all test token expirations to future time (datetime.now() + timedelta(hours=1))

### Challenge 2: Windows Unicode Encoding
**Problem**: Emoji characters (✓) causing UnicodeEncodeError
**Solution**: Removed emoji from print statements, used ASCII-friendly output

### Challenge 3: Large File Creation via Bash
**Problem**: Complex Python code with triple quotes couldn't be piped via bash heredoc
**Solution**: Used Write tool instead, which handles file writing natively
